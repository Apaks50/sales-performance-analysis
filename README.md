# Sales Performance Analysis and Revenue Optimization Using Data Analytics

## Project Overview
This project analyses Nigerian e-commerce sales data to identify sales trends, top-performing products, vendor performance and revenue patterns.

The project was carried out during my IT training at AICIC Concepts Limited.

## Tools Used
- Microsoft Excel – Data cleaning and preparation
- SQL Server – Database management and analysis
- Power BI – Data visualization and dashboard development

## Dataset
- Source: Kaggle
- Period: February – May 2021
- Records: 3,928

## Key Findings
- Total Revenue: ₦1,227,420,031.43
- Total Quantity Sold: 142,867
- Delivered Orders: 1,055
- Unique Products: 270
- Top Product: Milo Sachet 20g
- Highest Revenue Month: May 2021

## Project Objectives
- Clean and prepare sales data.
- Analyse sales performance using SQL.
- Identify top-performing products and vendors.
- Develop a Power BI dashboard.
- Provide recommendations based on findings.
